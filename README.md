# SpacecraftOS
An Operating System with a space theme based on spaceships.

<img style="width: 275px; height: 250px;" src="SpacecraftOS Gif1.gif">

**TRY IT: TBC**

## Features
On SpacecraftOS you can:
1. Learn about Spacecrafts
2. Learn how to see spacecrafts like ISS on your sky
3. Watch polish astronaut (Sławosz Uznański) eating polish delicious dish (pierogi) on the ISS
4. Rate picturesque photos from telescopes
5. And if something inspires you, you can write it down in Notes app - Spacecraft Ideas
